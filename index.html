What can I run?
Edit setup() and loop(), then select Run sketch (⌘/Ctrl + Enter). The first edit downloads a C++ compiler. Compilation runs in your browser. The preview supports common TFT_eSPI drawing calls, Serial, Arduino timing, and CST816S touch-coordinate reads via Wire. Declare helper functions before calling them. Board-specific libraries and hardware peripherals need a local build.
